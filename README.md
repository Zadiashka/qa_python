add_new_book
Успешное добавление книги с корректной длиной имени (включая граничный случай 40 символов).
Отсечение некорректных имён (пустая строка, длина > 40).
Нельзя добавить одну и ту же книгу дважды.

set_book_genre
Установка корректного жанра для существующей книги.
Попытка установить несуществующий жанр не меняет текущий жанр.
Попытка установить жанр для несуществующей книги не создаёт запись.

get_book_genre
Возвращает жанр добавленной книги (включая пустую строку по умолчанию).
Возвращает None для книг, которых нет в словаре.

get_books_with_specific_genre
Возвращает список книг с заданным жанром.
Для неизвестного жанра возвращает пустой список.

get_books_genre
Возвращает текущий словарь books_genre и проверяется его содержимое.

get_books_for_children
Включает книги с детскими жанрами.
Исключает книги с возрастным рейтингом (genre_age_rating).
Исключает книги без жанра.

add_book_in_favorites / delete_book_from_favorites / get_list_of_favorites_books
-Добавление в избранное только существующих книг.
-Запрет дублирования в избранном.
-Удаление из избранного и безопасное удаление несуществующих записей.
-Получение списка избранных книг.
